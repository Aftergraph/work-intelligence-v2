## External GitHub write blocker

The active GitHub connector can read the Aftergraph organization and its repositories, including governance, research, and WORKS, but both branch creation and Contents API writes to Aftergraph returned HTTP 403 `Resource not accessible by integration` on 2026-09-05. The implementation is therefore locally complete and packaged for import; no claim is made that it has been committed to the Aftergraph organization.
